# Header 导航栏优化设计

## 背景

当前 Header 存在以下问题：
- 6 个导航项平铺，信息层级不清晰
- "路线图/入门层/工作流层" 是三层入口，"工具选择/卡点排障/首次实践" 是功能页，混在一起
- 移动端完全没有导航（hidden xl:flex）
- CTA 按钮文字过长

## 设计决策

### 导航结构：极简导航

只保留核心入口：路线图（首页）、卡点排障、首次实践。其他页面通过首页卡片或 footer 进入。

### 移动端：汉堡菜单

点击菜单图标展开导航菜单，包含核心 3 项 + 次要入口（工具选择、安装验证）。

## 变更清单

| 项目 | 变更前 | 变更后 |
|------|--------|--------|
| 导航项 | 6 项平铺 | 3 项（路线图、卡点排障、首次实践） |
| CTA 按钮 | "开始第一次任务" | "开始任务" |
| 移动端导航 | 无 | 汉堡菜单（核心 3 项 + 次要 2 项） |
| Logo 区域 | Logo + 站名 + 副标题 | Logo + 站名 |

## 实现要点

### 桌面端 Header

```
[Logo] [AI Navigator] | [路线图] [卡点排障] [首次实践] | [开始任务]
```

- 导航项居中，使用 pill 形态
- 当前页面高亮（背景色）
- CTA 按钮保持黑色圆角按钮样式

### 移动端 Header

**收起状态：**
```
[Logo] [AI Navigator] | [☰] [开始]
```

**展开状态（汉堡菜单）：**
```
[AI Navigator]                              [✕]

🧭 路线图  ← 高亮
⚠️ 卡点排障
💻 首次实践
─────────────
⚙️ 工具选择
📦 安装验证
```

- 菜单从顶部滑入，覆盖内容
- 核心导航用常规字号，次要入口略小
- 点击菜单项后自动收起

## 组件结构

```
App.tsx
├── Header
│   ├── Logo
│   ├── Nav (desktop: visible, mobile: hidden)
│   ├── MobileMenuButton (desktop: hidden, mobile: visible)
│   ├── MobileMenu (conditional render)
│   └── CTAButton
```

## 响应式断点

- `xl` (1280px) 以上：显示完整桌面导航
- `xl` 以下：显示汉堡菜单按钮
