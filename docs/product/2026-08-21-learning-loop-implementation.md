# 学习闭环改版实施说明

状态：已完成
日期：2026-08-21
依据：`learning-and-design-baseline.md`

## 本次目标

让第一次访问的学生不必先判断自己属于哪个层级，而是从“做一个小目标、解决一个具体问题、寻找一个真实方向”三种当前状态中开始，并在一次行动后留下可复查证据和一条可复用经验。

## 页面契约

| 页面 | 用户目标 | 唯一默认主动作 | 完成证据 | 数据来源 | 视觉回归范围 |
|---|---|---|---|---|---|
| 安装确认 | 建立后续学习共同依赖的固定基础 | 回答 Claude Code、Codex 与 WorkBuddy 是否已经安装好 | 用户自我确认；没有或不确定时打开对应资料核对 | Claude Code 官方说明；卡兹克的 Codex / WorkBuddy 公众号文章标为 `Community Signal` | 1440px / 390px 问题、两种回答与按需展开状态 |
| 首页 | 立即开始一次低风险行动 | 打开一个 20 分钟小任务 | 产物、验证结果、复盘记录 | `PRACTICE_TASKS`、`ROADMAP_NODES` | 1440px / 390px 首屏、入口卡、渐进路线 |

## 数据改动

- 在既有 `Source` 事实记录之上增加 `SourceRecord`：补齐证据用途、适用范围和审核状态。
- 增加 `SourceSite` 聚合模型：按 Anthropic、OpenAI、基础工具、研究/社区、校园记录组织来源。
- 不修改仍在使用的 `sourceIds`，避免破坏路线、实践和更新记录的事实链。

## 保留边界

- 保留 `/starter`、`/project`、`/advanced` 作为渐进深度和协作入口。
- 保留全部实践详情、规则模板和安全指南；移除排障详情与站内助手。
- 不改变现有纸张底色、噪点、点阵、字体、克制色板、圆角、阴影与动效语言。
- 不新增未经官方核验的产品事实。

## 验收

1. 首页首屏只有一个黑色主 CTA，并在 10 秒内说明“现在能做什么”。
2. 实践卡明确时间、边界、交付物、至少三条验收证据和复盘入口。
3. 站内不再维护排障页；页面只提示用户把完整报错或截图交给可用的 AI。
4. 来源页默认按站点聚合，并显示用途、范围、核查日期和审核状态。
5. 个人笔记只保存在浏览器本地，不上传；能导出为 Markdown 文本。
6. 内容测试、TypeScript、生产构建、HTTP smoke 与桌面/移动浏览器 smoke 通过。

## 实施结果

- 页脚展示维护者 GitHub：`@BallCard`。
- 反馈入口使用预填 GitHub Issue，因此静态托管和 Sites 部署均可直接工作。
- 全站增加可关闭的更新说明，概括“从查教程转向做中生长”的调整；关闭状态仅保存在当前浏览器。
- 原排障页面、站内排障助手、助手 API 与对应产品文档已移除；旧地址重定向到首页。
- 后续若改为匿名站内反馈，应使用 Sites D1 等平台持久化能力，不得用 `localStorage` 冒充已送达的用户反馈。
